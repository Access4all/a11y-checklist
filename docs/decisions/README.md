# Decisions

Append-only log of decisions about this repository's content model and tooling, one file per decision named `YYYY-MM-DD-short-slug.md` after the day it was made. New entries are added with the `/log-decision` command (see [.claude/commands/log-decision.md](../../.claude/commands/log-decision.md)), which also defines the entry format.

Entries have no numbers and are not listed here: parallel branches would pick the same number or edit the same line and conflict on merge (see [2026-10-29-one-file-per-decision.md](2026-10-29-one-file-per-decision.md)). The folder listing, sorted by name, is the chronological index.
